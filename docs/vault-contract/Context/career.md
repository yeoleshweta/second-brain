# Career — classifier context

Mirrors `Career/Profile/` in short form so the (future) hourly classifier can route without loading four files.

Until the profile is filled, treat as career if the note is about: job, role, resume, interview, promotion, skills vs a target path, professional goals.

Not career: papers/reading list (Ross), meals/workouts (Monica), spend/Plaid (Finance), calendar/people notes (Chandler).
